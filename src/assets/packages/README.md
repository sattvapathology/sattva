# Package Illustrations

Place package illustration PNG files in this directory using these exact filenames:

- `basic-body-profile.png` (Basic Body Profile)
- `advanced-body-profile.png` (Advanced Body Profile)
- `advanced-diabetic-profile.png` (Advanced + Diabetic Profile)
- `silver-body-profile.png` (Silver Body Profile)
- `gold-body-profile.png` (Gold Body Profile)
- `male-executive-profile.png` (Male Executive Profile)
- `female-executive-profile.png` (Female Executive Profile)
- `diabetic-profile.png` (Diabetic Profile)

## Technical Specifications

- **Format**: PNG with transparent background.
- **Rendering**: Rendered in the top-right header area of each package card with `object-fit: contain`.
- **Dimensions**: Displayed at approximately 88–112px square on desktop, 64–80px square on mobile.
- **Fallback**: When an image file is absent, an unobtrusive empty space is reserved to prevent layout shift.
