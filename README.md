# Sattva Pathology Laboratory

Official website for Sattva Pathology Laboratory, Ahmedabad.

## Tech Stack

- **Framework**: TanStack Start (React 19)
- **Styling**: Tailwind CSS v4
- **Routing**: TanStack Router
- **Build / Bundler**: Vite 8 & Nitro

## Development

```sh
bun install
bun run dev
```

## Production Build & Test

```sh
bun run test
bun run lint
bun run build
```
